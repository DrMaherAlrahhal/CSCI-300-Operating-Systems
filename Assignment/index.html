Task 1 · 2 marks · CLO1

Operating System Selection

CLO1: Recommend the operating system for a given computing system based on efficient resource management.

Official Task 1 questions:
  1. Compare Windows and Linux based on resource management, software compatibility, security, and cost.
  2. Recommend the operating system for a given computing system based on efficient resource management. Justify your recommendation for the university computer laboratory.

Situation: A university is creating a computer lab for programming, web browsing and office applications.

Understand the ideas

An operating system (OS) manages hardware resources and provides services to applications. The CPU scheduler decides which ready process runs next; memory management assigns and protects RAM; the file system manages stored files.

CPU Scheduling Simulator

CLO3: Select the suitable process scheduling algorithm for a given computing problem.

Official Task 2 questions:

  2. Calculate completion time, turnaround time, waiting time, and average waiting time for each algorithm.

  4. Select the suitable process scheduling algorithm for a given computing problem. Use your calculated average waiting times to justify the selection.

Key definitions

Arrival time (AT): when a process becomes ready. Burst time (BT): CPU time it needs. Completion time (CT): when it finishes. Turnaround time (TAT): CT − AT. Waiting time (WT): TAT − BT. Average waiting: sum of waiting times divided by number of processes.

Small example, not your assignment dataset: A arrives at 0 and runs for 3 ms. If it completes at 3 ms, then TAT = 3 − 0 = 3 ms and WT = 3 − 3 = 0 ms.

Algorithm explanations

FCFS — First Come, First Served

Execute processes in order of arrival. A running process finishes before the next starts. If the CPU is idle, move the clock to the next arrival.

SJF — Shortest Job First (non-preemptive)

Whenever the CPU becomes free, look only at processes that have already arrived. Choose the one with the shortest burst time. Once it starts, let it finish. Define a tie-breaking rule (for example, earlier arrival then process ID).

Round Robin — 2 ms quantum

Maintain a ready queue. Run the front process for at most 2 ms, add newly arrived processes to the queue, and requeue an unfinished process at the back. Record completion when remaining burst reaches zero. State how you handle arrivals exactly at a quantum boundary.

Implementation plan in C

1
Create a struct Process with ID, arrival, burst, remaining, completion and other calculated fields.
2
Write a separate scheduling function for each algorithm. Reset the process data before each run.
3
Record every CPU interval: process ID, start time and end time.
4
Calculate CT, TAT and WT. Print a labeled result table and a text Gantt chart.
5
Compare average waiting times; recommend the algorithm with the smallest value for this dataset.

  • Choosing SJF by burst time without checking arrival time.

Task 3 · 2 marks · CLO4

Memory Page Replacement

CLO4: Select the optimal paging technique for a given computing system, working in teams and communicating.

Official Task 3 questions:
  1. Implement FIFO and LRU page replacement algorithms.
  2. Show the frame contents after each page request.
  3. Calculate the total page faults for both algorithms.
  4. Select the optimal paging technique for a given computing system, working in teams and communicating. Compare FIFO and LRU results to justify the selected technique.
  5. Present your page replacement results, explain the selected algorithm, and include a group contribution table showing each member’s responsibilities.

Situation: Three physical memory frames are available. Implement FIFO and LRU in C.

Official reference string: 7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2

Frames: 3

Understand the concepts

A page is a block of virtual memory; a frame is a slot in physical memory. A page hit occurs when the requested page is already loaded. A page fault occurs when it is not in a frame. If all frames are occupied, a replacement algorithm chooses a page to remove.

FIFO — First In, First Out

When replacement is necessary, remove the page that has been in memory the longest. A page hit does not change the FIFO insertion order.

LRU — Least Recently Used

When replacement is necessary, remove the page that has not been accessed for the longest time. Both hits and newly loaded pages update recency.

Small walkthrough with a different reference string

Example: 1, 2, 3, 1, 4, with 3 frames. After the first three requests, frames contain 1, 2, 3. The next request for 1 is a hit. When 4 arrives, FIFO replaces 1 (oldest loaded); LRU replaces 2 (least recently accessed). This is an example only, not the assignment solution.

How to implement

1
Initialize three empty frames and a page-fault counter.
2
For each page in the reference string, check whether it is already in a frame.
3
If absent, count a fault. Use an empty frame if available; otherwise apply FIFO or LRU.
4
Print the frame contents and Hit/Fault status after every request.
5
Compare the two total fault counts and justify your recommendation for this specific sequence.
