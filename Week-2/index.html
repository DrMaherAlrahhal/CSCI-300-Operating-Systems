1. Operating-System Services

Question: What does the OS provide when you run an application?

The Operating System provides program execution, file management, I/O operations, communication, resource allocation, and protection. Applications use these services instead of directly controlling hardware.

Example: When VS Code saves project.c, the OS manages the file operation.

2. System Calls

Question: How does VS Code ask the OS to open a file?

A system call is a controlled request from an application to the OS. The kernel handles the requested operation and returns a result.

🔁 Click through a system call

Main Types of System Calls

Process Control

Create and manage processes.

File Management

Open, read, write, and close files.

Device Management

Access devices.

Information Maintenance

Obtain or update system information.

Communication

Exchange information.

Protection

Control access to resources.

Connection: System calls are requests to the kernel. The OS also provides useful programs that people can run directly.

4. Linkers and Loaders

Question: Can the CPU directly execute the C source code you wrote?

No. A compiler translates source code into an object file. A linker combines object files and required libraries to create an executable. A loader prepares the executable in memory for execution.

Remember: The linker creates the executable; the loader prepares it in memory.

5. Operating-System Design and Implementation

Question: How do we plan and build a complex OS?

Design plans what the OS should do and how its parts should work together. Implementation builds the OS according to that design. Important goals include performance, reliability, security, and maintainability.

6. Operating-System Structure

Question: How are OS components organized?

OS structure describes how components are organized and how they interact. A simple conceptual view connects Applications, OS Services, Kernel, and Hardware.

🎓 Three Important Exam Questions

Try answering before opening the suggested answer.

1. Explain the difference between Operating-System Services and System Calls, using an example.

Operating-System Services are functions provided by the OS, such as file management, program execution, and device access. System calls allow applications to request these services. For example, when VS Code needs to open project.c, it makes a system call. The kernel handles the file operation and returns the result.

2. Explain the complete journey of a C program from source code to execution.

A programmer writes source code, such as main.c. The compiler translates it into an object file. The linker combines object files and required libraries to create an executable. The loader prepares the executable in memory, allowing the CPU to execute its instructions.

3. Explain the difference between OS design and OS structure, including policy and mechanism.

OS design focuses on planning how the Operating System should work, while implementation builds the system. Policy describes what should be done, and mechanism describes how it is carried out. OS structure organizes components and their interactions. Examples include monolithic, layered, microkernel, and modular structures.
