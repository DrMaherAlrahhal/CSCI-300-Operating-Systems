Week 3 · Revision

Week 3 Summary – Processes

What Did We Learn This Week?

In Week 3, we learned what happens after a program starts running. Imagine you open Chrome on your laptop. Chrome is a program stored on your computer, but when you open it, the OS manages it as a process. When Chrome, Teams, and VS Code are running, the OS uses process scheduling to decide which process gets CPU time. The OS also creates, runs, and terminates processes. Sometimes processes need to share information, so they use Interprocess Communication (IPC) through shared memory or message passing. We also learned about client–server communication, such as a browser requesting a webpage from a web server.

Important Terms to Remember

1. Program

A program is a set of instructions stored on a computer. For example, Chrome installed on your laptop is a program.

2. Process

A process is a program that is currently running. For example, opening Chrome creates a running process managed by the OS.

3. Process Scheduling

Process scheduling is how the OS chooses which ready process gets CPU time. It helps several programs share the CPU.

4. Ready Queue

The ready queue holds processes that are waiting for CPU time. The scheduler selects a process from this queue to run.

5. Process Creation

Process creation happens when the OS starts a new process. For example, opening VS Code starts a process.

6. Process Termination

Process termination happens when a process finishes or is stopped. For example, closing an application normally ends its process.

7. Interprocess Communication (IPC)

IPC allows processes to exchange information and work together. Two common methods are shared memory and message passing.

8. Shared Memory

Shared memory lets processes read and write data in the same memory area. They must coordinate access to avoid conflicts.

9. Message Passing

Message passing lets processes communicate by sending and receiving messages. They do not need to access the same shared memory area.

10. Client–Server Communication

A client sends a request, and a server sends back a response. For example, Chrome requests a webpage from a web server.

Exam preparation

3 Important Exam Questions

Try answering each question before revealing the model answer.

1. Explain the difference between a program and a process, and why process scheduling is necessary.
A program is a collection of instructions stored on disk, while a process is a program currently executing. Several processes may need CPU time. The OS coordinates their execution through process scheduling. The scheduler selects a process to receive CPU time.
2. Compare shared-memory IPC and message-passing IPC.
Both methods allow processes to exchange information. In shared-memory IPC, processes communicate through a common memory area. In message-passing IPC, processes send and receive messages. Both support cooperation, but they use different methods to exchange information.
3. Describe process creation, execution, termination, and one example of client–server communication.
The OS creates a process when an application starts, manages it while executing, and handles its termination when it finishes. Processes can also communicate with other processes or systems. For example, a browser sends a request to a web server, and the server returns a response.
