6. Three Exam-Style Questions

Think through each question before revealing the suggested answer.

Question 1 — Compare a process and a thread. Why is synchronization necessary?

A process is a running program with its own resources and address space. A thread is an execution path within a process, typically sharing its process's memory. Synchronization is needed when threads access shared data so operations do not interfere and produce incorrect results. A mutex can protect a critical section.

Question 2 — Explain how paging helps memory management and what causes thrashing.

Paging divides virtual memory into pages and physical memory into frames. A page table maps pages to frames, allowing noncontiguous allocation. When required pages are not in memory, page faults occur. Thrashing happens when the system spends excessive effort moving pages between RAM and storage rather than executing useful work, often because the working sets exceed available memory.

Question 3 — A server freezes because two threads wait for each other's locks. Explain the problem and suggest a solution.

This is a deadlock scenario involving circular waiting. Deadlock requires mutual exclusion, hold and wait, no preemption, and circular wait. One practical prevention technique is to require all threads to acquire multiple locks in the same global order. Detection and recovery may also be used where prevention is unsuitable.
