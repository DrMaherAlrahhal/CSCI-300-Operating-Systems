Week 1 · Revision

Week 1 Summary: Introduction to Operating Systems

What Did We Learn This Week?

In Week 1, we learned how the Operating System (OS) helps a computer work. Imagine you open VS Code, Chrome, and other applications. The OS manages these programs and helps them use the CPU, RAM, storage, and devices. When you open an application, it becomes a process, and the OS manages its execution. The OS also uses interrupts to respond to events, such as pressing a key. Through multiprogramming, the CPU can work on another program while one is waiting. We also learned how the OS manages resources, protects information, and uses the kernel to control important system operations.

Important Terms to Remember

Each term has a short, simple definition. Show or hide definitions to review with students.

1. Operating System (OS)

An Operating System is software that manages computer hardware and helps applications run. Examples include Windows, Linux, and macOS.

2. CPU (Central Processing Unit)

The CPU executes instructions and performs calculations. It runs the instructions of programs such as VS Code and Chrome.

3. RAM (Random Access Memory)

RAM temporarily stores programs and data while they are being used. Its contents are normally lost when the computer is turned off.

4. SSD (Solid-State Drive)

An SSD stores programs, files, and data until they are deleted. Unlike RAM, it keeps data when the computer is turned off.

5. Program and Process

A program is a set of instructions stored on a computer. A process is a program that is currently running.

6. Device Controller

A device controller is hardware that helps the computer communicate with a device. For example, a keyboard controller helps manage keyboard input.

7. Interrupt

An interrupt is a signal that tells the CPU an event needs attention. For example, a keyboard event can generate an interrupt that the OS handles.

8. Multiprogramming

Multiprogramming keeps multiple programs in memory so the CPU can work on another program when one is waiting.

9. Resource Management

Resource management means the OS controls and shares CPU time, memory, storage, and devices among different programs.

10. Protection and Security

Protection controls which programs or users can access resources. Security protects the computer from threats such as viruses and unauthorized access.

11. Kernel

The kernel is the core part of the Operating System. It manages processes, memory, and communication with hardware.

Remember the Complete Journey

Open an Application → Program Becomes a Process → OS Allocates CPU and RAM → CPU Executes Instructions → Interrupts Handle Events → OS Manages and Protects Resources

The Operating System manages all these activities, while the kernel performs essential operations that help the computer run correctly.

Chapter 13 · Prepare for the exam

Three exam-style questions

Think and discuss before revealing the suggested response.

Q1. How does the OS manage resources when Chrome, VS Code, and Teams run together?

The OS manages processes, allocates memory, shares CPU time among ready processes, coordinates I/O devices, and controls access to files and resources. This lets several applications make progress while using the same hardware.

Q2. What is an interrupt? Describe what happens when a student presses a key.

An interrupt is a signal that an event needs CPU attention. When a key is pressed, the keyboard controller reports the event; the CPU handles the interrupt through the OS, which processes the input and makes it available to the relevant application before normal execution continues.

Q3. Explain virtualization and distributed systems, then give one example of a kernel data structure.

Virtualization creates virtual computing environments, such as Ubuntu running in VirtualBox on Windows. A distributed system uses separate computers that cooperate through a network. A kernel may use a queue to organize processes waiting for a resource or service.
