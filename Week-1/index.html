1. Why do we need an Operating System?

Ask: Chrome and VS Code both need hardware. Who coordinates them?

An Operating System (OS) works between applications and hardware. Computer-system organization describes how the CPU, RAM, storage, and devices work together. Computer-system architecture describes the arrangement of processing components, including multiple CPU cores.

📝 Three Important Exam Questions

Question 1: How does the OS manage resources when several applications run together?

Show suggested answer

The Operating System manages CPU time, memory, storage, and devices. When several applications run together, they may request the same resources. The OS coordinates their use to support multiple programs. For example, Chrome, Teams, and VS Code share CPU time and RAM under OS management.

Question 2: Explain the difference between virtualization and distributed systems.

Show suggested answer

Virtualization allows a computer to run virtual computing environments. For example, Ubuntu can run inside VirtualBox on a Windows laptop. A distributed system involves multiple connected computers communicating and cooperating. The main difference is that virtualization creates virtual environments, while distributed systems connect cooperating computers.

Question 3: Why does the kernel need data structures? Give an example.

Show suggested answer

The kernel manages processes, memory, and other system resources. It needs data structures to organize and access system information efficiently. Examples include lists, queues, trees, and bitmaps. A queue can organize processes waiting for CPU time, making them easier for the OS to manage.
