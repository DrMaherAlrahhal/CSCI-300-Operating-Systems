TOPIC 01

File Concept

A file is a named collection of data stored on a device. The OS keeps file information such as name, size, type, location, and permissions.

Student example

A student saves report.txt; the file remains on storage after the app closes.

TOPIC 02

Access Methods

Sequential access reads data in order. Direct (random) access reads a chosen location without reading everything before it.

Student example

A music playlist is often read sequentially; a database may jump to a specific record.

TOPIC 03

Directory Structure

Directories organize files. A tree structure has folders and subfolders; an absolute path starts at the root, while a relative path starts from the current location.

Student example

/home/student/notes/week13.txt

TOPIC 04

Protection

File permissions control who may read, write, or execute a file. Permissions help prevent unauthorized access or modification.

Student example

A student can read a shared handout but cannot edit it.

TOPIC 05

Memory-Mapped Files

Memory mapping makes file contents accessible through a process’s virtual address space. The OS maps file pages into memory as needed.

Student example

An application accesses parts of a large file as memory instead of issuing an explicit read for every access.

TOPIC 06

File Systems

A file system organizes files, directories, and metadata on a storage volume. Different file systems use different formats and features.

Student example

NTFS is common on Windows; ext4 is common on Linux.

TOPIC 07

File-System Mounting

Mounting makes a file system accessible at a location in the directory tree. The mounted file system can then be accessed through that path.

Student example

A USB drive is mounted and its files become accessible.

TOPIC 08

Partitions and Mounting

A storage device may be divided into partitions. Each partition may contain a file system, and a file system must be mounted to access it through the OS directory tree.

Student example

One disk can contain a system partition and a data partition.

TOPIC 09

File Sharing

File sharing lets users or computers access the same files. The OS must manage permissions and simultaneous access.

Student example

Students access a shared course folder on a network.

TOPIC 10

Virtual File Systems

A Virtual File System (VFS) provides a common interface to different file-system implementations, so applications use familiar file operations regardless of the underlying format.

Student example

An app opens files using the same interface even if they are stored on different supported file systems.

EXAM PRACTICE

3 Short-Answer Questions

Think about each answer before opening it.

Question 1: Explain file access methods and give one example of each.

Sequential access reads data in order, such as processing a log from beginning to end. Direct access jumps to a selected location, such as retrieving a particular database record.

Question 2: Explain the relationship between partitions, file systems, and mounting.

A disk can be divided into partitions. A partition may hold a file system that organizes files and directories. Mounting makes that file system accessible at a location in the OS directory tree.

Question 3: What is a Virtual File System (VFS), and why is it useful?

VFS provides a common file-operation interface to different file systems. Applications can open and read files without needing separate interfaces for every supported file-system type.
