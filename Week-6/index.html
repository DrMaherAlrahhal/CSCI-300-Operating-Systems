01 • Multi-Processor Scheduling

What if the computer has more than one CPU core?

A multicore computer can execute different tasks on different cores at the same time. The scheduler decides which task runs on which core. It also tries to keep cores busy without moving tasks unnecessarily.

Load Balancing

Spread runnable work across available CPU cores.

Processor Affinity

Prefer keeping a task on the same core when helpful for cache performance.

Symmetric Multiprocessing

Each processor can participate in scheduling work.

02 • Real-Time CPU Scheduling

What if a task must finish before a deadline?

In real-time systems, when a result arrives can be as important as the result itself. A scheduler considers task deadlines and timing requirements.

Hard Real-Time

Missing a deadline is considered a system failure. Example: a critical safety-control function.

Soft Real-Time

Missing a deadline reduces quality, but may not cause total failure. Example: a video playback frame.

Two key scheduling ideas: Rate-Monotonic Scheduling (RMS) uses fixed priorities, usually favoring tasks with shorter periods. Earliest Deadline First (EDF) dynamically favors the task with the closest absolute deadline.

03 • Operating-System Examples

How do real operating systems schedule work?

Real operating systems use sophisticated scheduling policies and different priority classes. The details vary by version and configuration.

Linux

Uses scheduler classes for different workloads, including normal and real-time tasks. Modern Linux kernels use a fair-scheduling approach for ordinary tasks.

Windows

Uses preemptive, priority-driven scheduling, with multiple priority levels and support for scheduling threads across processors.

Real-Time OS

Systems such as FreeRTOS commonly use priority-based scheduling designed for embedded tasks with timing needs.

04 • Algorithm Evaluation

How do we compare scheduling algorithms?

We evaluate algorithms against the goals of the workload. Common measurements include CPU utilization, throughput, turnaround time, waiting time, response time, and for real-time tasks, deadline misses.

Waiting Time

How long a process waits in the ready queue.

Turnaround Time

Completion time minus arrival time.

Response Time

First CPU start minus arrival time.

Throughput

Number of completed tasks per unit of time.

Interactive: Compare FCFS and SJF

Key idea: No single algorithm is best for every workload. Select an algorithm using the system's goals and measured results.
