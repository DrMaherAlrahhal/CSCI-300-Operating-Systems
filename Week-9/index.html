1. Background — Why Memory Management?

Programs must have their instructions and active data in RAM while they execute. The OS tracks which memory is available, assigns memory to processes, and helps keep one process from improperly accessing another process's memory.

Remember: RAM is limited. The OS must decide how to use it efficiently.

2. Contiguous Memory Allocation

In contiguous allocation, each process occupies one continuous block of physical memory. This is easy to visualize, but free memory can become separated into small gaps. That is called external fragmentation.

Interactive RAM allocator

Imagine 16 equal memory units. The OS occupies the first 2 units. Add and remove processes to see how gaps appear.

Key idea: Even when total free space is sufficient, a process may not fit if no single gap is large enough.

Connection: Paging helps avoid the need for one continuous physical memory block.

3. Paging — Divide Memory into Fixed-Size Blocks

Paging divides a process's logical memory into fixed-size pages and physical RAM into equally sized frames. Pages from one process can be stored in different frames.

Important: Paging removes external fragmentation for page-sized allocations, but the last page may leave unused space inside a frame (internal fragmentation).

Connection: If pages are scattered across frames, the OS needs a map to find them.

4. Structure of the Page Table

A page table maps a process's virtual page numbers to physical frame numbers. A virtual address is split into a page number and an offset. The page table supplies the frame number; the offset stays the same.

5. Swapping — Moving Memory Contents

Swapping moves process memory contents between RAM and backing storage to help manage memory pressure. The OS may move data out of RAM and bring it back when needed. Modern systems often swap memory pages rather than whole processes.

Exam Practice — 3 Questions

Question 1

Explain why an operating system needs memory management. Give two responsibilities.

The OS allocates RAM to active processes, tracks free and used memory, and helps protect one process's memory from unauthorized access by another. These functions let several applications run safely and efficiently.

Question 2

Compare contiguous memory allocation and paging. Explain external fragmentation.

Contiguous allocation places each process in one continuous physical memory block. Paging divides logical memory into pages and RAM into equal-size frames, allowing a process's pages to occupy separate frames. External fragmentation happens when free memory is split into small gaps; paging avoids this type of fragmentation for page-sized allocations.

Question 3

Page size = 100 bytes. Virtual address = 230. Page 2 maps to frame 7. Calculate the physical address.

Virtual page = floor(230 / 100) = 2. Offset = 230 mod 100 = 30. Physical address = (7 × 100) + 30 = 730.
