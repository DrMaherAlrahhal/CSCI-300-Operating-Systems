Lesson 1 – How Can a Thread Identify Itself?

Use pthread_self() and pthread_equal() to compare threads.

📖 First: Explanation and Example

Every thread has an identifier. pthread_self() gets the identifier of the currently running thread. pthread_equal() checks whether two thread identifiers refer to the same thread. The main thread and a new worker thread are different.

pthread_self()Get the identifier of the current thread.
pthread_tType used to store a thread identifier.
pthread_equal(a, b)Check whether two thread IDs identify the same thread.
pthread_join()Wait for a worker thread to finish.
nano thread_identity.cgcc -Wall -Wextra -pthread thread_identity.c -o thread_identity./thread_identity
thread_identity.c — example C program
#include <stdio.h>
#include <pthread.h>

pthread_t main_thread;

void *worker(void *arg) {
    (void)arg;
    pthread_t worker_thread = pthread_self();
    printf("Worker: I have started.\n");

    if (pthread_equal(worker_thread, main_thread)) {
        printf("Worker: Same as main thread.\n");
    } else {
        printf("Worker: Different from main thread.\n");
    }
    return NULL;
}

int main(void) {
    pthread_t thread;
    main_thread = pthread_self();
    printf("Main: Creating a worker thread.\n");

    if (pthread_create(&thread, NULL, worker, NULL) != 0) {
        fprintf(stderr, "Thread creation failed.\n");
        return 1;
    }
    pthread_join(thread, NULL);
    printf("Main: Worker finished.\n");
    return 0;
}
Example Ubuntu Terminal output
Main: Creating a worker thread.
Worker: I have started.
Worker: Different from main thread.
Main: Worker finished.
💡 Do not compare pthread_t values using ==. Use pthread_equal() for a portable thread identity check.

Lesson 2 – How Can a Thread Return a Result?

Use pthread_exit() and pthread_join() to pass back a value.

📖 First: Explanation and Example

A worker can finish and return a result to the main thread. pthread_exit() supplies a pointer to the result. pthread_join() waits for the thread and receives that pointer. In this example, the result is stored in a static variable, so it remains valid after the worker finishes.

pthread_exit(&result)Finish a thread and return a pointer to its result.
pthread_join(thread, &value)Wait for the thread and collect the returned pointer.
static int resultKeep the result alive after the function finishes.
*(int *)valueRead the integer stored at the returned pointer.
nano thread_result.cgcc -Wall -Wextra -pthread thread_result.c -o thread_result./thread_result
thread_result.c — example C program
#include <stdio.h>
#include <pthread.h>

void *worker(void *arg) {
    (void)arg;
    static int result = 25;
    printf("Worker: Calculation complete.\n");
    pthread_exit(&result);
}

int main(void) {
    pthread_t thread;
    void *value = NULL;

    if (pthread_create(&thread, NULL, worker, NULL) != 0) {
        fprintf(stderr, "Thread creation failed.\n");
        return 1;
    }
    if (pthread_join(thread, &value) != 0) {
        fprintf(stderr, "Could not join thread.\n");
        return 1;
    }

    printf("Main: Received result = %d\n", *(int *)value);
    return 0;
}
Example Ubuntu Terminal output
Worker: Calculation complete.
Main: Received result = 25
💡 Never return the address of a normal local variable from a finished thread. That variable no longer exists. This example uses static storage for one worker.

Lesson 3 – How Can We Manage Several Threads?

Create three workers, pass each a task, and collect all results.

📖 First: Explanation and Example

An application may need several threads. We can create a thread for each task, give each thread different data, and join every thread before reading its result. Each worker updates only its own task record, so this example does not need a mutex.

pthread_t threads[3]Store three worker thread identifiers.
Task tasks[3]Store a separate input and output for each worker.
pthread_create(..., &tasks[i])Pass a unique task record to each worker.
pthread_join(threads[i], NULL)Wait for every worker before printing its result.
nano manage_workers.cgcc -Wall -Wextra -pthread manage_workers.c -o manage_workers./manage_workers
manage_workers.c — example C program
#include <stdio.h>
#include <pthread.h>

typedef struct {
    int id;
    int number;
    int square;
} Task;

void *calculate(void *arg) {
    Task *task = (Task *)arg;
    task->square = task->number * task->number;
    return NULL;
}

int main(void) {
    pthread_t threads[3];
    Task tasks[3] = {{1, 2, 0}, {2, 3, 0}, {3, 4, 0}};

    for (int i = 0; i < 3; i++) {
        if (pthread_create(&threads[i], NULL,
                           calculate, &tasks[i]) != 0) {
            fprintf(stderr, "Thread creation failed.\n");
            return 1;
        }
    }

    for (int i = 0; i < 3; i++) {
        pthread_join(threads[i], NULL);
        printf("Task %d: %d squared = %d\n",
               tasks[i].id, tasks[i].number, tasks[i].square);
    }
    return 0;
}
Example Ubuntu Terminal output
Task 1: 2 squared = 4
Task 2: 3 squared = 9
Task 3: 4 squared = 16
💡 The order in which threads execute is not guaranteed. This example prints results in a stable order because the main thread prints after joining each worker.

Lesson 4 – How Can We Stop a Running Thread Safely?

Request cancellation and confirm it with pthread_join().

📖 First: Explanation and Example

Sometimes the main thread must stop a worker before it finishes naturally. pthread_cancel() requests cancellation. The worker responds at a cancellation point, such as nanosleep() or pthread_testcancel(). After that, pthread_join() confirms that the thread ended. A condition variable is used here to make sure the worker has started before cancellation is requested.

pthread_cancel(thread)Ask a running thread to stop.
pthread_testcancel()Give the worker a cancellation point.
pthread_join(thread, &status)Wait until cancellation has completed.
status == PTHREAD_CANCELEDCheck whether the worker was cancelled.
nano cancel_worker.cgcc -Wall -Wextra -pthread cancel_worker.c -o cancel_worker./cancel_worker
cancel_worker.c — example C program
#include <stdio.h>
#include <pthread.h>
#include <time.h>

pthread_mutex_t mutex = PTHREAD_MUTEX_INITIALIZER;
pthread_cond_t ready_cond = PTHREAD_COND_INITIALIZER;
int ready = 0;

void *worker(void *arg) {
    (void)arg;
    printf("Worker: Started.\n");

    pthread_mutex_lock(&mutex);
    ready = 1;
    pthread_cond_signal(&ready_cond);
    pthread_mutex_unlock(&mutex);

    for (;;) {
        pthread_testcancel();
        struct timespec pause = {0, 100000000L};
        nanosleep(&pause, NULL);
    }
    return NULL;
}

int main(void) {
    pthread_t thread;
    void *status = NULL;

    if (pthread_create(&thread, NULL, worker, NULL) != 0) {
        fprintf(stderr, "Thread creation failed.\n");
        return 1;
    }

    pthread_mutex_lock(&mutex);
    while (!ready) {
        pthread_cond_wait(&ready_cond, &mutex);
    }
    pthread_mutex_unlock(&mutex);

    printf("Main: Requesting cancellation.\n");
    pthread_cancel(thread);
    pthread_join(thread, &status);

    if (status == PTHREAD_CANCELED) {
        printf("Main: Worker was cancelled.\n");
    }
    pthread_cond_destroy(&ready_cond);
    pthread_mutex_destroy(&mutex);
    return 0;
}
Example Ubuntu Terminal output
Worker: Started.
Main: Requesting cancellation.
Main: Worker was cancelled.
💡 pthread_cancel() does not immediately kill a thread. Cancellation normally happens at a cancellation point. The program uses a condition variable to avoid relying on timing guesses.
