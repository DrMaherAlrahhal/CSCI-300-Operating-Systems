Basics of Shell: From Commands to Your First Script

In previous labs, you used Linux commands to work with files and folders. In Week 4, learn how the shell works, store information in variables, save output to files, connect commands with pipes, and create your first Bash script. First learn, then complete the student tasks in Ubuntu.

🎯 Learning outcomes

01 · Understand the shell

Explain Terminal vs Bash and use simple commands.

02 · Work with text

Use variables, user input, redirection and pipes.

03 · Write a script

Create, save, permit and execute a simple .sh script.

Why are we learning this? The shell is how many operating system tasks are automated. Rather than entering the same commands again and again, we can connect commands and save them in a script. These skills are useful for system administration, development and later Operating Systems labs.
