Lesson 1 – How Does FCFS Choose the Next Process?

Run processes in arrival order and calculate waiting time.

📖 First: Explanation and Example

First Come, First Served (FCFS) runs the process that arrived first. FCFS is non-preemptive: once a process starts, it runs until its CPU burst finishes. When all processes arrive at time 0, the given order is the FCFS order.

Burst Time (BT)How long a process needs the CPU.
Waiting Time (WT)Time spent waiting before CPU execution.
Turnaround Time (TAT)Time from arrival to completion.
TAT = WT + BTWhen the process runs without interruption.
nano fcfs_basic.cgcc -Wall -Wextra fcfs_basic.c -o fcfs_basic./fcfs_basic
fcfs_basic.c — example C program
#include <stdio.h>

int main(void) {
    int burst[] = {4, 3, 2};
    int waiting[3], turnaround[3];
    int time = 0;

    printf("Process  BT  WT  TAT\n");
    for (int i = 0; i < 3; i++) {
        waiting[i] = time;
        time += burst[i];
        turnaround[i] = time;
        printf("P%d       %d   %d    %d\n",
               i + 1, burst[i], waiting[i], turnaround[i]);
    }
    printf("Total CPU time: %d\n", time);
    return 0;
}
Example Ubuntu Terminal output
Process  BT  WT  TAT
P1       4   0    4
P2       3   4    7
P3       2   7    9
Total CPU time: 9
💡 With all arrivals at 0, the waiting time of each process equals the sum of the burst times before it.

Lesson 2 – What Happens When Processes Arrive at Different Times?

Use arrival times and notice when the CPU is idle.

📖 First: Explanation and Example

A process cannot run before it arrives. The start time is the later of the CPU becoming free and the process arrival time. If no process has arrived, the CPU stays idle. Here the processes are already listed in arrival order.

Arrival Time (AT)The time a process enters the ready queue.
Start = max(time, AT)Do not start before the process arrives.
WT = Start − ATHow long the process waits.
TAT = Finish − ATTotal time in the system.
nano fcfs_arrival.cgcc -Wall -Wextra fcfs_arrival.c -o fcfs_arrival./fcfs_arrival
fcfs_arrival.c — example C program
#include <stdio.h>

typedef struct {
    int arrival;
    int burst;
} Process;

int main(void) {
    Process p[3] = {{0, 3}, {2, 2}, {4, 4}};
    int time = 0;

    printf("Process  AT  BT  Start  Finish  WT  TAT\n");
    for (int i = 0; i < 3; i++) {
        if (time < p[i].arrival) {
            printf("CPU idle: %d to %d\n", time, p[i].arrival);
            time = p[i].arrival;
        }
        int start = time;
        time += p[i].burst;
        int wt = start - p[i].arrival;
        int tat = time - p[i].arrival;
        printf("P%d        %d   %d     %d       %d    %d    %d\n",
               i + 1, p[i].arrival, p[i].burst,
               start, time, wt, tat);
    }
    return 0;
}
Example Ubuntu Terminal output
Process  AT  BT  Start  Finish  WT  TAT
P1        0   3     0       3    0    3
P2        2   2     3       5    1    3
P3        4   4     5       9    1    5
💡 The modified data produces CPU idle time from 3 to 5. P3 arrives at 6 but starts at 7, so its waiting time is 1.

Lesson 3 – How Can We Build an FCFS Schedule and Gantt Chart?

Sort processes by arrival and calculate average waiting and turnaround times.

📖 First: Explanation and Example

Processes may be entered in a different order from their arrival times. FCFS sorts them by arrival time. If arrival times are equal, this example keeps the original input order. A Gantt chart shows which process uses the CPU at each time interval.

Sort by arrivalEarlier arrival gets the CPU first.
Stable tie ruleKeep original input order when arrivals match.
Gantt chartShow process start and finish times.
Average WT / TATAdd each value and divide by the number of processes.
nano fcfs_gantt.cgcc -Wall -Wextra fcfs_gantt.c -o fcfs_gantt./fcfs_gantt
fcfs_gantt.c — example C program
#include <stdio.h>

typedef struct {
    int id, arrival, burst;
} Process;

int main(void) {
    Process p[4] = {
        {1, 4, 2}, {2, 0, 3}, {3, 2, 4}, {4, 2, 1}
    };
    int time = 0, total_wt = 0, total_tat = 0;

    /* Stable insertion sort by arrival time. */
    for (int i = 1; i < 4; i++) {
        Process key = p[i];
        int j = i - 1;
        while (j >= 0 && p[j].arrival > key.arrival) {
            p[j + 1] = p[j];
            j--;
        }
        p[j + 1] = key;
    }

    printf("Gantt chart intervals:\n");
    printf("Process  AT  BT  Start  End  WT  TAT\n");
    for (int i = 0; i < 4; i++) {
        if (time < p[i].arrival) {
            printf("Idle: %d-%d\n", time, p[i].arrival);
            time = p[i].arrival;
        }
        int start = time;
        time += p[i].burst;
        int wt = start - p[i].arrival;
        int tat = time - p[i].arrival;
        total_wt += wt;
        total_tat += tat;
        printf("P%d        %d   %d     %d    %d    %d    %d\n",
               p[i].id, p[i].arrival, p[i].burst,
               start, time, wt, tat);
    }
    printf("Average WT: %.2f\n", total_wt / 4.0);
    printf("Average TAT: %.2f\n", total_tat / 4.0);
    return 0;
}
Example Ubuntu Terminal output
Gantt chart intervals:
Process  AT  BT  Start  End  WT  TAT
P2        0   3     0    3    0    3
P3        2   4     3    7    1    5
P4        2   1     7    8    5    6
P1        4   2     8    10    4    6
Average WT: 2.50
Average TAT: 5.00
💡 Changing P1 burst from 2 to 5 changes P1 completion and turnaround times, but P1 is last, so average waiting time stays 2.50. Average turnaround becomes 5.75.

Lesson 4 – How Can We Schedule Processes Entered by the User?

Read arrival and burst times, validate them, and compute FCFS results.

📖 First: Explanation and Example

A useful FCFS program should accept different process data instead of using fixed numbers. This program asks for the number of processes and their arrival/burst times, sorts by arrival, prints the execution intervals, and calculates average waiting and turnaround times.

scanf()Read the process data entered in Terminal.
Stable sortRun the earliest arrivals first; preserve input order for ties.
Idle intervalShow gaps when the CPU has no ready process.
AveragesCalculate and display mean waiting and turnaround times.
nano fcfs_input.cgcc -Wall -Wextra fcfs_input.c -o fcfs_input./fcfs_input
fcfs_input.c — example C program
#include <stdio.h>

#define MAX 10

typedef struct {
    int id, arrival, burst;
} Process;

int main(void) {
    Process p[MAX];
    int n, time = 0;
    int total_wt = 0, total_tat = 0;

    printf("Number of processes (1-10): ");
    if (scanf("%d", &n) != 1 || n < 1 || n > MAX) {
        printf("Invalid number of processes.\n");
        return 1;
    }
    for (int i = 0; i < n; i++) {
        p[i].id = i + 1;
        printf("P%d arrival and burst: ", i + 1);
        if (scanf("%d %d", &p[i].arrival, &p[i].burst) != 2 ||
            p[i].arrival < 0 || p[i].burst <= 0) {
            printf("Invalid process data.\n");
            return 1;
        }
    }

    for (int i = 1; i < n; i++) {
        Process key = p[i];
        int j = i - 1;
        while (j >= 0 && p[j].arrival > key.arrival) {
            p[j + 1] = p[j];
            j--;
        }
        p[j + 1] = key;
    }

    printf("\nFCFS schedule:\n");
    printf("Process  AT  BT  Start  End  WT  TAT\n");
    for (int i = 0; i < n; i++) {
        if (time < p[i].arrival) {
            printf("CPU idle: %d-%d\n", time, p[i].arrival);
            time = p[i].arrival;
        }
        int start = time;
        time += p[i].burst;
        int wt = start - p[i].arrival;
        int tat = time - p[i].arrival;
        total_wt += wt;
        total_tat += tat;
        printf("P%d        %d   %d     %d    %d    %d    %d\n",
               p[i].id, p[i].arrival, p[i].burst,
               start, time, wt, tat);
    }
    printf("Average WT: %.2f\n", (double)total_wt / n);
    printf("Average TAT: %.2f\n", (double)total_tat / n);
    return 0;
}
Example Ubuntu Terminal output

P1 arrival and burst: 0 4
P2 arrival and burst: 1 3
P3 arrival and burst: 6 2

FCFS schedule:
Process  AT  BT  Start  End  WT  TAT
P1        0   4     0    4    0    4
P2        1   3     4    7    3    6
P3        6   2     7    9    1    3
Average WT: 1.33
Average TAT: 4.33
💡 For the four-process test, the CPU is idle from 2 to 5 and from 9 to 9 is not an interval. P4 begins at 9. Average WT is 0.75 and average TAT is 2.75.
