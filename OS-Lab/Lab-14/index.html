Lesson 1 – How Can C Find Information About a File?

Use stat() to check file size and type.

📖 First: Explanation and Example

The operating system stores information about files, such as their size and type. A C program can request this information using stat(). First, create a sample file in Ubuntu, then let the program inspect it.

stat("sample.txt", &info)Read information about sample.txt.
struct statStore information returned by stat().
info.st_sizeFind the file size in bytes.
S_ISREG(info.st_mode)Check whether the path is a regular file.
nano file_info.cgcc -std=c11 -D_POSIX_C_SOURCE=200809L -Wall -Wextra file_info.c -o file_info./file_info
printf 'Hello Linux\n' > sample.txt
file_info.c — example C program
#include <stdio.h>
#include <sys/stat.h>

int main(void) {
    struct stat info;

    if (stat("sample.txt", &info) == -1) {
        perror("stat");
        return 1;
    }

    printf("File: sample.txt\n");
    printf("Size: %lld bytes\n", (long long)info.st_size);

    if (S_ISREG(info.st_mode)) {
        printf("Type: regular file\n");
    } else if (S_ISDIR(info.st_mode)) {
        printf("Type: directory\n");
    } else {
        printf("Type: another file type\n");
    }
    return 0;
}
Example Ubuntu Terminal output
File: sample.txt
Size: 12 bytes
Type: regular file
💡 The file must exist in the same working folder as the program. Use pwd and ls to check your location.

Lesson 2 – How Can a C Program List a Directory?

Use opendir(), readdir(), and closedir().

📖 First: Explanation and Example

A directory stores entries for files and subdirectories. C can open a directory and read its entries one at a time. In this example, you will create a small folder containing two files and display their names.

opendir("lab14")Open the lab14 directory.
readdir(dir)Read the next directory entry.
entry->d_nameGet the entry name.
closedir(dir)Close the directory when finished.
nano list_files.cgcc -std=c11 -D_POSIX_C_SOURCE=200809L -Wall -Wextra list_files.c -o list_files./list_files
mkdir -p lab14 && touch lab14/alpha.txt lab14/beta.txt
list_files.c — example C program
#include <stdio.h>
#include <string.h>
#include <dirent.h>

int main(void) {
    DIR *dir = opendir("lab14");
    if (dir == NULL) {
        perror("opendir");
        return 1;
    }

    struct dirent *entry;
    int count = 0;
    while ((entry = readdir(dir)) != NULL) {
        if (strcmp(entry->d_name, ".") == 0 ||
            strcmp(entry->d_name, "..") == 0) {
            continue;
        }
        printf("Found: %s\n", entry->d_name);
        count++;
    }

    if (closedir(dir) == -1) {
        perror("closedir");
        return 1;
    }
    printf("Total entries: %d\n", count);
    return 0;
}
Example Ubuntu Terminal output
Found: alpha.txt
Found: beta.txt
Total entries: 2
💡 The order of file names returned by readdir() is not guaranteed. The total number of entries is the important result.

Lesson 3 – How Can C Create, Rename, and Remove Files?

Use mkdir(), open(), rename(), unlink(), and rmdir().

📖 First: Explanation and Example

File system operations let a program organize its own working files. This example creates a temporary practice folder, creates a file inside it, renames the file, and removes both. It works only with the specially named lab folder.

mkdir(path, 0700)Create a directory.
open(path, O_CREAT | O_EXCL, 0600)Create a new file only if it does not exist.
rename(old, new)Rename the created file.
unlink(path) / rmdir(path)Remove the file, then the empty directory.
nano manage_files.cgcc -std=c11 -D_POSIX_C_SOURCE=200809L -Wall -Wextra manage_files.c -o manage_files./manage_files
manage_files.c — example C program
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>

int main(void) {
    const char *folder = "lab14_work";
    const char *old_name = "lab14_work/notes.txt";
    const char *new_name = "lab14_work/report.txt";

    if (mkdir(folder, 0700) == -1) {
        perror("mkdir");
        return 1;
    }
    printf("Created directory: %s\n", folder);

    int fd = open(old_name, O_WRONLY | O_CREAT | O_EXCL, 0600);
    if (fd == -1) {
        perror("open");
        return 1;
    }
    if (close(fd) == -1) {
        perror("close");
        return 1;
    }
    printf("Created file: notes.txt\n");

    if (rename(old_name, new_name) == -1) {
        perror("rename");
        return 1;
    }
    printf("Renamed file: report.txt\n");

    if (unlink(new_name) == -1) {
        perror("unlink");
        return 1;
    }
    printf("Removed file: report.txt\n");

    if (rmdir(folder) == -1) {
        perror("rmdir");
        return 1;
    }
    printf("Removed empty directory: %s\n", folder);
    return 0;
}
Example Ubuntu Terminal output
Created directory: lab14_work
Created file: notes.txt
Renamed file: report.txt
Removed file: report.txt
Removed empty directory: lab14_work
💡 The example creates and deletes only its own lab14_work folder. Do not change the paths to personal or system folders. If lab14_work already exists, the program stops instead of modifying it.

Lesson 4 – How Can C Copy a File and Control Permissions?

Use open(), read(), write(), close(), and fchmod().

📖 First: Explanation and Example

File copying combines several file system calls. A program opens a source file, reads its bytes, writes them to a new file, and sets permissions. This example refuses to overwrite an existing destination and reports the total bytes copied.

open()Open a source file or create a new destination.
read() / write()Read bytes and write them to the destination.
fchmod(fd, 0600)Give the owner read and write permission only.
O_EXCLRefuse to overwrite an existing destination file.
nano copy_file.cgcc -std=c11 -D_POSIX_C_SOURCE=200809L -Wall -Wextra copy_file.c -o copy_file./copy_file
printf 'CSCI 300 Week 14\nFile systems in C\n' > source.txt
copy_file.c — example C program
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>
#include <sys/stat.h>
#include <errno.h>

int main(void) {
    int src = open("source.txt", O_RDONLY);
    if (src == -1) {
        perror("open source");
        return 1;
    }

    int dst = open("copy.txt", O_WRONLY | O_CREAT | O_EXCL, 0600);
    if (dst == -1) {
        perror("open destination");
        close(src);
        return 1;
    }

    char buffer[256];
    ssize_t n;
    long long total = 0;
    while ((n = read(src, buffer, sizeof(buffer))) > 0) {
        ssize_t written = 0;
        while (written < n) {
            ssize_t m = write(dst, buffer + written, (size_t)(n - written));
            if (m == -1 && errno == EINTR) continue;
            if (m <= 0) {
                perror("write");
                close(src);
                close(dst);
                return 1;
            }
            written += m;
        }
        total += n;
    }
    if (n == -1) {
        perror("read");
        close(src);
        close(dst);
        return 1;
    }
    if (fchmod(dst, 0600) == -1) {
        perror("fchmod");
        close(src);
        close(dst);
        return 1;
    }
    if (close(src) == -1 || close(dst) == -1) {
        perror("close");
        return 1;
    }
    printf("Copy completed: %lld bytes.\n", total);
    printf("Destination permissions: 600\n");
    return 0;
}
Example Ubuntu Terminal output
Copy completed: 35 bytes.
Destination permissions: 600
💡 The output size depends on the source text. The program uses 0600 permissions: only the file owner can read and write. It will refuse to overwrite copy.txt or backup.txt if either already exists.
