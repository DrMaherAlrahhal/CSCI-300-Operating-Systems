Lesson 1 – How Does SJF Choose the Next Process?

Choose the shortest CPU burst when all processes are ready.

📖 First: Explanation and Example

Shortest Job First (SJF) selects the ready process with the smallest CPU burst. In this lab, we use non-preemptive SJF: once a process starts, it finishes before another process runs. When all processes arrive at time 0, we can order them by burst time.

Burst Time (BT)How many CPU time units a process needs.
Shortest firstChoose the ready process with the smallest burst.
Waiting Time (WT)Time before the process starts (when AT = 0).
Turnaround Time (TAT)Completion time when arrival time is 0.
nano sjf_basic.cgcc -Wall -Wextra sjf_basic.c -o sjf_basic./sjf_basic
sjf_basic.c — example C program
#include <stdio.h>

typedef struct {
    int id, burst;
} Process;

int main(void) {
    Process p[3] = {{1, 6}, {2, 2}, {3, 4}};
    int time = 0;

    /* Sort by burst time (shortest first). */
    for (int i = 0; i < 3; i++) {
        for (int j = i + 1; j < 3; j++) {
            if (p[j].burst < p[i].burst) {
                Process temp = p[i];
                p[i] = p[j];
                p[j] = temp;
            }
        }
    }

    printf("Process  BT  WT  TAT\n");
    for (int i = 0; i < 3; i++) {
        int wt = time;
        time += p[i].burst;
        int tat = time;
        printf("P%d       %d   %d    %d\n",
               p[i].id, p[i].burst, wt, tat);
    }
    return 0;
}
Example Ubuntu Terminal output
Process  BT  WT  TAT
P2       2   0    2
P3       4   2    6
P1       6   6    12
💡 With all processes ready at time 0, the order is based on burst time. With different arrivals, SJF must choose only among processes that have already arrived.

Lesson 2 – Can a New Shorter Process Interrupt the CPU?

See how non-preemptive SJF handles different arrival times.

📖 First: Explanation and Example

SJF must consider arrival time. When the CPU becomes free, it chooses the shortest burst among the processes that have already arrived. A shorter process arriving while another is running does not interrupt it in non-preemptive SJF.

Arrival Time (AT)When a process becomes ready.
Ready processesOnly processes with AT at or before the current time.
Non-preemptiveA running process is not interrupted.
WT = Start − ATTime spent waiting for CPU.
nano sjf_arrival.cgcc -Wall -Wextra sjf_arrival.c -o sjf_arrival./sjf_arrival
sjf_arrival.c — example C program
#include <stdio.h>

typedef struct {
    int id, arrival, burst, done;
} Process;

int main(void) {
    Process p[3] = {
        {1, 0, 6, 0}, {2, 1, 2, 0}, {3, 2, 1, 0}
    };
    int time = 0;

    printf("Process  AT  BT  Start  End  WT  TAT\n");
    for (int finished = 0; finished < 3; finished++) {
        int best = -1;
        for (int i = 0; i < 3; i++) {
            if (!p[i].done && p[i].arrival <= time &&
                (best == -1 || p[i].burst < p[best].burst)) {
                best = i;
            }
        }
        if (best == -1) {
            int next = -1;
            for (int i = 0; i < 3; i++) {
                if (!p[i].done &&
                    (next == -1 || p[i].arrival < p[next].arrival)) {
                    next = i;
                }
            }
            printf("CPU idle: %d-%d\n", time, p[next].arrival);
            time = p[next].arrival;
            best = next;
        }
        int start = time;
        time += p[best].burst;
        int wt = start - p[best].arrival;
        int tat = time - p[best].arrival;
        p[best].done = 1;
        printf("P%d        %d   %d     %d    %d    %d    %d\n",
               p[best].id, p[best].arrival, p[best].burst,
               start, time, wt, tat);
    }
    return 0;
}

P3        2   1     6    7    4    5

Lesson 3 – How Can We Draw an SJF Gantt Chart?

Choose among ready processes and calculate average WT and TAT.

📖 First: Explanation and Example

A Gantt chart shows the execution intervals. For different arrival times, SJF must choose the shortest ready process each time the CPU becomes free. This program also calculates average waiting and turnaround times.

Gantt intervalEach process start and finish time.
Dynamic selectionSelect the shortest among processes that are ready now.
Tie ruleFor equal bursts, prefer earlier arrival, then lower process ID.
Average WT / TATSum the waiting / turnaround times and divide by process count.
nano sjf_gantt.cgcc -Wall -Wextra sjf_gantt.c -o sjf_gantt./sjf_gantt
sjf_gantt.c — example C program
#include <stdio.h>

typedef struct {
    int id, arrival, burst, done;
} Process;

int main(void) {
    Process p[4] = {
        {1, 0, 5, 0}, {2, 1, 3, 0},
        {3, 2, 1, 0}, {4, 4, 2, 0}
    };
    int time = 0, total_wt = 0, total_tat = 0;

    printf("SJF Gantt intervals:\n");
    printf("Process  AT  BT  Start  End  WT  TAT\n");
    for (int finished = 0; finished < 4; finished++) {
        int best = -1;
        for (int i = 0; i < 4; i++) {
            if (p[i].done || p[i].arrival > time) continue;
            if (best == -1 || p[i].burst < p[best].burst ||
                (p[i].burst == p[best].burst &&
                 (p[i].arrival < p[best].arrival ||
                  (p[i].arrival == p[best].arrival &&
                   p[i].id < p[best].id)))) {
                best = i;
            }
        }
        if (best == -1) {
            int next = -1;
            for (int i = 0; i < 4; i++) {
                if (!p[i].done &&
                    (next == -1 || p[i].arrival < p[next].arrival)) {
                    next = i;
                }
            }
            printf("CPU idle: %d-%d\n", time, p[next].arrival);
            time = p[next].arrival;
            best = next;
        }
        int start = time;
        time += p[best].burst;
        int wt = start - p[best].arrival;
        int tat = time - p[best].arrival;
        total_wt += wt;
        total_tat += tat;
        p[best].done = 1;
        printf("P%d        %d   %d     %d    %d    %d    %d\n",
               p[best].id, p[best].arrival, p[best].burst,
               start, time, wt, tat);
    }
    printf("Average WT: %.2f\n", total_wt / 4.0);
    printf("Average TAT: %.2f\n", total_tat / 4.0);
    return 0;
}

Lesson 4 – How Can We Build an SJF Scheduler with User Input?

Read process data, calculate a schedule, and test special cases.

📖 First: Explanation and Example

A reusable scheduler accepts process arrival and burst times from the user. This C program validates the input, selects the shortest ready job, shows CPU idle time when needed, and calculates averages. It uses non-preemptive SJF.

scanf()Read the number of processes and their data.
Ready queueOnly arrived, unfinished processes are eligible.
Input validationRequire non-negative arrival and positive burst times.
Tie ruleEqual bursts: earlier arrival first, then lower process ID.
nano sjf_input.cgcc -Wall -Wextra sjf_input.c -o sjf_input./sjf_input
sjf_input.c — example C program
#include <stdio.h>

#define MAX 10

typedef struct {
    int id, arrival, burst, done;
} Process;

int main(void) {
    Process p[MAX];
    int n, time = 0;
    int total_wt = 0, total_tat = 0;

    printf("Number of processes (1-10): ");
    if (scanf("%d", &n) != 1 || n < 1 || n > MAX) {
        printf("Invalid number of processes.\n");
        return 1;
    }
    for (int i = 0; i < n; i++) {
        p[i].id = i + 1;
        p[i].done = 0;
        printf("P%d arrival and burst: ", i + 1);
        if (scanf("%d %d", &p[i].arrival, &p[i].burst) != 2 ||
            p[i].arrival < 0 || p[i].burst <= 0) {
            printf("Invalid process data.\n");
            return 1;
        }
    }

    printf("\nNon-preemptive SJF schedule:\n");
    printf("Process  AT  BT  Start  End  WT  TAT\n");
    for (int finished = 0; finished < n; finished++) {
        int best = -1;
        for (int i = 0; i < n; i++) {
            if (p[i].done || p[i].arrival > time) continue;
            if (best == -1 || p[i].burst < p[best].burst ||
                (p[i].burst == p[best].burst &&
                 (p[i].arrival < p[best].arrival ||
                  (p[i].arrival == p[best].arrival &&
                   p[i].id < p[best].id)))) {
                best = i;
            }
        }
        if (best == -1) {
            int next = -1;
            for (int i = 0; i < n; i++) {
                if (!p[i].done &&
                    (next == -1 || p[i].arrival < p[next].arrival ||
                     (p[i].arrival == p[next].arrival &&
                      p[i].id < p[next].id))) {
                    next = i;
                }
            }
            printf("CPU idle: %d-%d\n", time, p[next].arrival);
            time = p[next].arrival;
            best = next;
        }
        int start = time;
        time += p[best].burst;
        int wt = start - p[best].arrival;
        int tat = time - p[best].arrival;
        total_wt += wt;
        total_tat += tat;
        p[best].done = 1;
        printf("P%d        %d   %d     %d    %d    %d    %d\n",
               p[best].id, p[best].arrival, p[best].burst,
               start, time, wt, tat);
    }
    printf("Average WT: %.2f\n", (double)total_wt / n);
    printf("Average TAT: %.2f\n", (double)total_tat / n);
    return 0;
}
