Lesson 1 – How Can a C Program Create Its First Thread?

Use pthread_create() and pthread_join() to run a worker function.

📖 First: Explanation and Example

A thread is a path of execution inside a process. Threads in the same process share memory. The main function runs in the main thread; pthread_create() starts another thread to run a function, and pthread_join() waits for that thread to finish.

#include <pthread.h>Provides the POSIX thread (pthread) functions.
pthread_t workerStores the thread identifier.
pthread_create()Starts a thread that runs a function.
pthread_join()Waits until the created thread finishes.
nano first_thread.cgcc -Wall -Wextra -pthread first_thread.c -o first_thread./first_thread
first_thread.c — example C program
#include <stdio.h>
#include <pthread.h>

void *worker(void *arg) {
    (void)arg;
    printf("Worker: Hello from a new thread!\n");
    return NULL;
}

int main(void) {
    pthread_t thread;
    printf("Main: Starting a worker thread.\n");

    if (pthread_create(&thread, NULL, worker, NULL) != 0) {
        fprintf(stderr, "Could not create thread.\n");
        return 1;
    }
    pthread_join(thread, NULL);
    printf("Main: Worker finished.\n");
    return 0;
}
Example Ubuntu Terminal output
Main: Starting a worker thread.
Worker: Hello from a new thread!
Main: Worker finished.
💡 Always compile these programs with -pthread. A thread runs a function with the form void *function(void *arg).

Lesson 2 – How Can We Pass Information to a Thread?

Give a worker thread a student name as an argument.

📖 First: Explanation and Example

We can send data to a thread when it starts. pthread_create() passes its fourth argument to the worker function. The worker can read that value and use it in a message.

void *argThe worker receives its input through this pointer.
(const char *)argInterpret the pointer as text.
pthread_create(..., name)Pass the name to the worker.
pthread_join()Keep main waiting until the worker uses the name.
nano thread_message.cgcc -Wall -Wextra -pthread thread_message.c -o thread_message./thread_message
thread_message.c — example C program
#include <stdio.h>
#include <pthread.h>

void *welcome(void *arg) {
    const char *name = (const char *)arg;
    printf("Worker: Welcome, %s!\n", name);
    printf("Worker: This is CSCI 300.\n");
    return NULL;
}

int main(void) {
    pthread_t thread;
    char name[] = "Sara";

    if (pthread_create(&thread, NULL, welcome, name) != 0) {
        fprintf(stderr, "Could not create thread.\n");
        return 1;
    }
    pthread_join(thread, NULL);
    printf("Main: Greeting completed.\n");
    return 0;
}
Example Ubuntu Terminal output
Worker: Welcome, Sara!
Worker: This is CSCI 300.
Main: Greeting completed.
💡 The name array is stored in main. Waiting with pthread_join() ensures main does not finish before the worker uses it.

Lesson 3 – How Can Two Threads Work at the Same Time?

Create two worker threads and observe their output.

📖 First: Explanation and Example

Two threads can make progress independently. The operating system decides when each one runs, so their printed messages may appear in a different order each time. We use pthread_join() to wait for both workers before displaying the final message.

pthread_t threads[2]Store identifiers for two worker threads.
pthread_create() twiceStart two workers.
for loop in workerRepeat a task in each thread.
pthread_join() twiceWait for both workers to finish.
nano two_threads.cgcc -Wall -Wextra -pthread two_threads.c -o two_threads./two_threads
two_threads.c — example C program
#include <stdio.h>
#include <pthread.h>

typedef struct {
    int id;
    int repeats;
} ThreadData;

void *show_numbers(void *arg) {
    ThreadData *data = (ThreadData *)arg;
    for (int i = 1; i <= data->repeats; i++) {
        printf("Thread %d: step %d\n", data->id, i);
    }
    return NULL;
}

int main(void) {
    pthread_t threads[2];
    ThreadData data[2] = {{1, 3}, {2, 3}};

    for (int i = 0; i < 2; i++) {
        if (pthread_create(&threads[i], NULL,
                           show_numbers, &data[i]) != 0) {
            fprintf(stderr, "Could not create thread.\n");
            return 1;
        }
    }
    for (int i = 0; i < 2; i++) {
        pthread_join(threads[i], NULL);
    }
    printf("Main: Both threads finished.\n");
    return 0;
}
Example Ubuntu Terminal output
Thread 1: step 1
Thread 1: step 2
Thread 1: step 3
Thread 2: step 1
Thread 2: step 2
Thread 2: step 3
Main: Both threads finished.

(The order of thread messages may change.)
💡 Both threads should finish before the final main message. The order of messages from Thread 1 and Thread 2 is not fixed.

Lesson 4 – How Can Threads Safely Update Shared Data?

Use a mutex to protect a shared counter.

📖 First: Explanation and Example

Threads share memory, so two threads can try to update the same variable at the same time. A mutex allows only one thread at a time to change the shared counter. Without synchronization, updates can be lost and the result is not reliable.

pthread_mutex_tA mutex that protects shared data.
pthread_mutex_lock()Enter the protected section.
counter++Update the shared value.
pthread_mutex_unlock()Allow another thread to enter.
nano safe_counter.cgcc -Wall -Wextra -pthread safe_counter.c -o safe_counter./safe_counter
safe_counter.c — example C program
#include <stdio.h>
#include <pthread.h>

#define THREADS 2
#define INCREMENTS 100000

long counter = 0;
pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER;

void *increase(void *arg) {
    (void)arg;
    for (int i = 0; i < INCREMENTS; i++) {
        pthread_mutex_lock(&lock);
        counter++;
        pthread_mutex_unlock(&lock);
    }
    return NULL;
}

int main(void) {
    pthread_t threads[THREADS];

    for (int i = 0; i < THREADS; i++) {
        if (pthread_create(&threads[i], NULL,
                           increase, NULL) != 0) {
            fprintf(stderr, "Could not create thread.\n");
            return 1;
        }
    }
    for (int i = 0; i < THREADS; i++) {
        pthread_join(threads[i], NULL);
    }

    printf("Expected counter: %d\n", THREADS * INCREMENTS);
    printf("Actual counter: %ld\n", counter);
    pthread_mutex_destroy(&lock);
    return 0;
}
Example Ubuntu Terminal output
Expected counter: 200000
Actual counter: 200000
💡 Keep pthread_mutex_lock() and pthread_mutex_unlock() around counter++. Do not remove the mutex: that would create a data race.
