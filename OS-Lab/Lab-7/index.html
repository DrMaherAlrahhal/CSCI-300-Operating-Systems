Lesson 1 – How Can a Shell Script Make a Decision?

Use if and else to choose one result.

📖 First: Explanation and Example

A shell script can make decisions by checking a condition. For example, it can read a student's age and display a different message depending on whether the age is 18 or above.

read -rAccept an answer typed by the user.
if ... thenStart a decision.
(( age >= 18 ))Check whether age is at least 18.
else / fiChoose the other result / end the decision.
nano age_check.shbash age_check.sh
age_check.sh — example Bash script
#!/bin/bash
echo "CSCI 300 - Age Check"
read -r -p "Enter your age: " age

if [[ ! "$age" =~ ^[0-9]+$ ]]; then
    echo "Please enter a whole number."
elif (( age >= 18 )); then
    echo "You are 18 or older."
else
    echo "You are under 18."
fi
Example Terminal result
Enter your age: 20
You are 18 or older.

Run again:
Enter your age: 16
You are under 18.
💡 In Bash, spaces matter around [[ ... ]] and after if. Save your file before running it.

Lesson 2 – How Can We Repeat a Command?

Use a for loop to print a sequence of numbers.

📖 First: Explanation and Example

Instead of typing the same echo command many times, we can use a loop. A for loop repeats the instructions for a list of values.

for number in {1..5}Repeat for numbers 1, 2, 3, 4, and 5.
doStart the repeated instructions.
echoPrint the current number.
doneFinish the loop.
nano count.shbash count.sh
count.sh — example Bash script
#!/bin/bash
echo "CSCI 300 - Counting"

for number in {1..5}
do
    echo "Number: $number"
done

echo "Counting complete."
Example Terminal result
CSCI 300 - Counting
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Counting complete.
💡 The variable $number changes automatically each time the loop repeats.

Lesson 3 – How Can a Script Classify Student Marks?

Use if, elif and else to select one of several results.

📖 First: Explanation and Example

Sometimes there are more than two possible outcomes. We can use if, elif and else to check conditions in order. This script reads a mark and displays Excellent, Pass, or Needs Improvement.

if / elif / elseCheck several conditions, one after another.
(( mark >= 85 ))Excellent for marks 85 to 100.
(( mark >= 50 ))Pass for marks 50 to 84.
Input checkReject marks outside 0 to 100.
nano grade.shbash grade.sh
grade.sh — example Bash script
#!/bin/bash
echo "CSCI 300 - Grade Result"
read -r -p "Enter mark (0-100): " mark

if [[ ! "$mark" =~ ^[0-9]+$ ]] || (( mark > 100 )); then
    echo "Invalid mark."
elif (( mark >= 85 )); then
    echo "Result: Excellent"
elif (( mark >= 50 )); then
    echo "Result: Pass"
else
    echo "Result: Needs Improvement"
fi
Example Terminal result
Enter mark (0-100): 92
Result: Excellent

Run again:
Enter mark (0-100): 68
Result: Pass

Run again:
Enter mark (0-100): 34
Result: Needs Improvement

Run again:
Enter mark (0-100): 120
Invalid mark.
💡 The order of conditions matters. Check the highest threshold first.

Lesson 4 – How Can We Control a Loop While Calculating?

Use while, continue, and break to process numbers.

📖 First: Explanation and Example

A while loop repeats while its condition is true. We can use continue to skip one loop cycle and break to stop the loop early. Here we add numbers up to N, skip multiples of 3, and stop when the total reaches 20 or more.

while (( i < limit ))Keep repeating until i reaches the limit.
continueSkip the current number when divisible by 3.
breakStop early when the total reaches 20.
total=$((total + i))Add the current number to the total.
nano number_control.shbash number_control.sh
number_control.sh — example Bash script
#!/bin/bash
echo "CSCI 300 - Loop Control"
read -r -p "Enter limit (1-30): " limit

if [[ ! "$limit" =~ ^[0-9]+$ ]] || (( limit < 1 || limit > 30 )); then
    echo "Please enter a number from 1 to 30."
    exit 1
fi

i=0
total=0
while (( i < limit ))
do
    i=$((i + 1))

    if (( i % 3 == 0 )); then
        echo "Skipping $i"
        continue
    fi

    total=$((total + i))
    echo "Added $i -> Total: $total"

    if (( total >= 20 )); then
        echo "Target reached. Stopping."
        break
    fi
done

echo "Final total: $total"
Example Terminal result
Enter limit (1-30): 10
Added 1 -> Total: 1
Added 2 -> Total: 3
Skipping 3
Added 4 -> Total: 7
Added 5 -> Total: 12
Skipping 6
Added 7 -> Total: 19
Added 8 -> Total: 27
Target reached. Stopping.
Final total: 27
💡 Increase i before using continue. Otherwise the loop could repeat the same number forever.
