TASK 1 · Decision Making

How Can a Script Decide Based on Age?

Concept: if, elif, else and fi choose a result according to the user's input. read receives input from the keyboard.

1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create age_check.sh 
nano age_check.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

age_check.sh 
#!/bin/bash
echo "CSCI 300 - Age Check"
read -r -p "Enter your age: " age

if [[ ! "$age" =~ ^[0-9]+$ ]]; then
    echo "Please enter a whole number."
elif (( age >= 18 )); then
    echo "You are 18 or older."
else
    echo "You are under 18."
fi
3

Save the script and close Nano

Press Ctrl + O, then Enter to save. Press Ctrl + X to return to Ubuntu Terminal.

Your script is now saved in the Week 7 folder.

4

Run the script in Ubuntu Terminal

Type the command below and press Enter.

Run this command 
bash age_check.sh
5

Test the input values

Run the script again for each test value: 20, 16, and hello. Enter each value when the program asks for input.

6

Compare your results with the expected output

Expected: Age 20 → “You are 18 or older.” Age 16 → “You are under 18.” Invalid text → “Please enter a whole number.”

Upload your screenshots

TASK 2 · For Loop

How Can a Script Repeat a Command?

Concept: A for loop repeats commands for each value in a sequence. do begins the loop body and done ends it.

1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create count.sh 
nano count.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

count.sh 
#!/bin/bash
echo "CSCI 300 - Counting"

for number in {1..5}
do
    echo "Number: $number"
done

echo "Counting complete."
3

Save the script and close Nano

4

6

Compare your results with the expected output

TASK 3 · IF / ELIF / ELSE

Lesson 3 – How Can a Script Classify Student Marks?

Learning goal: Use if, elif and else to classify a student's mark into Excellent, Pass, or Needs Improvement. Reject invalid marks.

Understand the rules: 85–100 → Excellent · 50–84 → Pass · 0–49 → Needs Improvement · Above 100 or non-numeric → Invalid mark.
1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create grade.sh 
nano grade.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

grade.sh — Copy the complete Bash script 
#!/bin/bash
echo "CSCI 300 - Grade Result"
read -r -p "Enter mark (0-100): " mark

if [[ ! "$mark" =~ ^[0-9]+$ ]] || (( mark > 100 )); then
    echo "Invalid mark."
elif (( mark >= 85 )); then
    echo "Result: Excellent"
elif (( mark >= 50 )); then
    echo "Result: Pass"
else
    echo "Result: Needs Improvement"
fi
3

Save the script and close Nano
