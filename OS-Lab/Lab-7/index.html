TASK 1 · Decision Making

How Can a Script Decide Based on Age?

Concept: if, elif, else and fi choose a result according to the user's input. read receives input from the keyboard.

1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create age_check.sh 
nano age_check.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

age_check.sh 
#!/bin/bash
echo "CSCI 300 - Age Check"
read -r -p "Enter your age: " age

if [[ ! "$age" =~ ^[0-9]+$ ]]; then
    echo "Please enter a whole number."
elif (( age >= 18 )); then
    echo "You are 18 or older."
else
    echo "You are under 18."
fi

📖 Understand the code — line by line

Read each command and its simple explanation before running the script.

#!/bin/bashTells Ubuntu to use Bash to interpret this script.
echo "CSCI 300 - Age Check"Displays a heading in the terminal.
read -r -p "Enter your age: " ageAsks the user to type an age and saves it in the variable age.
if [[ ! "$age" =~ ^[0-9]+$ ]]; thenChecks whether the input is not a whole number. If it is invalid, run the next message.
echo "Please enter a whole number."Shows an error message for invalid input, such as hello.
elif (( age >= 18 )); thenIf the input is valid, checks whether the age is 18 or older.
echo "You are 18 or older."Shows this message when the age is 18 or more.
elseRuns the next instruction when the previous conditions are false.
echo "You are under 18."Shows this message when the age is below 18.
fiEnds the if / elif / else decision block.

TASK 2 · For Loop

How Can a Script Repeat a Command?

Concept: A for loop repeats commands for each value in a sequence. do begins the loop body and done ends it.

1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create count.sh 
nano count.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

count.sh 
#!/bin/bash
echo "CSCI 300 - Counting"

for number in {1..5}
do
    echo "Number: $number"
done

echo "Counting complete."

📖 Understand the code — line by line

Read each command and its simple explanation before running the script.

#!/bin/bashTells Ubuntu to run the script with Bash.
echo "CSCI 300 - Counting"Prints the title before counting begins.
for number in {1..5}Starts a for loop. The variable number takes the values 1, 2, 3, 4, and 5.
doMarks the beginning of the instructions that repeat.
echo "Number: $number"Prints the current number on each repetition. The $ symbol reads the variable.
doneEnds the loop after all five numbers have been processed.
echo "Counting complete."Displays a final message when the loop finishes.

TASK 3 · IF / ELIF / ELSE

Lesson 3 – How Can a Script Classify Student Marks?

Learning goal: Use if, elif and else to classify a student's mark into Excellent, Pass, or Needs Improvement. Reject invalid marks.

Understand the rules: 85–100 → Excellent · 50–84 → Pass · 0–49 → Needs Improvement · Above 100 or non-numeric → Invalid mark.
1

Create the script file

In Ubuntu Terminal, type the command below and press Enter. The Nano editor will open.

Create grade.sh 
nano grade.sh
2

Copy and paste the complete Bash code

Click Copy full script, then paste the code into Nano.

grade.sh — Copy the complete Bash script 
#!/bin/bash
echo "CSCI 300 - Grade Result"
read -r -p "Enter mark (0-100): " mark

if [[ ! "$mark" =~ ^[0-9]+$ ]] || (( mark > 100 )); then
    echo "Invalid mark."
elif (( mark >= 85 )); then
    echo "Result: Excellent"
elif (( mark >= 50 )); then
    echo "Result: Pass"
else
    echo "Result: Needs Improvement"
fi

📖 Understand the code — line by line

Read each command and its simple explanation before running the script.

#!/bin/bashRuns this script using Bash.
echo "CSCI 300 - Grade Result"Displays the title of the program.
read -r -p "Enter mark (0-100): " markAsks for a mark and stores the answer in the variable mark.
if [[ ! "$mark" =~ ^[0-9]+$ ]] || (( mark > 100 )); thenChecks for invalid input: not a whole number, or greater than 100. The || means OR.
echo "Invalid mark."Shows an error when the mark is invalid.
elif (( mark >= 85 )); thenChecks whether the valid mark is 85 or above.
echo "Result: Excellent"Prints Excellent for marks from 85 to 100.
elif (( mark >= 50 )); thenIf the mark is below 85, checks whether it is 50 or above.
echo "Result: Pass"Prints Pass for marks from 50 to 84.
elseHandles the remaining valid marks, which are below 50.
echo "Result: Needs Improvement"Prints Needs Improvement for marks from 0 to 49.
fiEnds the conditional block.
