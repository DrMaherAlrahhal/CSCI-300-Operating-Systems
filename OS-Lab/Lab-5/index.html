📄 Lesson 1 – How Can We Create and Run a Shell Program?

Write several commands in one script and execute them together.

📖 First: Explanation

In Week 4, we learned how the shell accepts commands. Instead of typing the same commands one by one, we can save them in a shell script and run them together. A shell script is a text file containing commands for the shell.

Script fileA file ending in .sh, such as welcome.sh.
First line#!/bin/bash tells the system which interpreter to use when the script is executed directly.
Display textecho prints a message.
Run scriptbash welcome.sh runs the script using Bash.

💻 Commands and Example Script

nano welcome.sh
bash welcome.sh
Script – welcome.sh
#!/bin/bash
echo "Welcome to CSCI 300"
echo "This is my first shell program"
date
Example Terminal output
student@ubuntu:~$ bash welcome.sh
Welcome to CSCI 300
This is my first shell program
[Current date and time]
💡 In nano, press Ctrl + O, then Enter to save; press Ctrl + X to exit. The date shown on your computer will be different.

⌨️ Lesson 2 – How Can a Script Ask for Student Information?

Store information in variables and read keyboard input.

📖 First: Explanation

A useful program should not always show the same information. With read, the shell can ask a user for information. Variables store the values so we can display them later.

Ask the userread -p displays a prompt and waits for input.
Store valuesstudent_name and student_id are variables.
Display values$student_name reads the saved value.
Quote the outputDouble quotes help preserve spaces in a name.

💻 Commands and Example Script

nano student.sh
bash student.sh
Script – student.sh
#!/bin/bash
read -p "Enter your name: " student_name
read -p "Enter your student ID: " student_id
echo "Student: $student_name"
echo "ID: $student_id"
echo "Course: CSCI 300"
Example Terminal output
student@ubuntu:~$ bash student.sh
Enter your name: Sara Ali
Enter your student ID: AUD12345
Student: Sara Ali
ID: AUD12345
Course: CSCI 300
💡 Do not add spaces around = when assigning a shell variable. In this example, read stores the values directly.

🔀 Lesson 3 – How Can a Shell Program Make a Decision?

Use a numeric comparison with if, else and fi.

📖 First: Explanation

Programs often need to choose between two results. For example, a student with a mark of 50 or more passes; otherwise the student needs improvement. A shell script can make that decision using if and else.

Get a markread -p asks for the value.
Compare numbers-ge means greater than or equal to.
Choose an actionif ... then ... else selects the correct message.
End the conditionfi closes the if statement.

💻 Commands and Example Script

nano result.sh
bash result.sh
Script – result.sh
#!/bin/bash
read -p "Enter your mark (0-100): " mark
if ! [[ "$mark" =~ ^[0-9]+$ ]] || (( mark < 0 || mark > 100 )); then
    echo "Please enter a valid mark from 0 to 100"
elif [ "$mark" -ge 50 ]; then
    echo "Result: Pass"
else
    echo "Result: Needs Improvement"
fi
Example Terminal output
student@ubuntu:~$ bash result.sh
Enter your mark (0-100): 75
Result: Pass

[Run again with 42]
Enter your mark (0-100): 42
Result: Needs Improvement
💡 Square brackets need spaces around their contents: [ "$mark" -ge 50 ]. The extra validation checks that the input is a whole number between 0 and 100.

🔁 Lesson 4 – How Can a Script Repeat a Task and Calculate a Total?

Use a for loop and arithmetic to process several values.

📖 First: Explanation

Suppose we want to process several numbers. Repeating echo and calculations manually is slow. A for loop repeats the same instructions, and $(( ... )) performs integer arithmetic.

Repeat a blockfor ... do ... done repeats commands.
Generate values{1..5} provides 1, 2, 3, 4 and 5.
Add each numbertotal=$((total + number)) updates the sum.
Show final resultecho displays the calculated total.

💻 Commands and Example Script

nano total.sh
bash total.sh
Script – total.sh
#!/bin/bash
total=0
for number in {1..5}
do
    echo "Number: $number"
    total=$((total + number))
done
echo "Total: $total"
Example Terminal output
student@ubuntu:~$ bash total.sh
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Total: 15
💡 The first total must be set to 0 before the loop. Every time the loop runs, the current number is added to total.
