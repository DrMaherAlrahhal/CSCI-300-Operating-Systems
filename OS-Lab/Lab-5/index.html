2 · ⌨️ How Can a Script Ask for Student Information?

First: Explanation. A useful program can ask the user for information. Bash uses read to accept keyboard input. Variables store the information so we can display it later.

Ask the userread -p displays a prompt and waits for input.
Store valuesstudent_name and student_id are variables.
Display values$student_name retrieves the stored value.
Keep spacesUse double quotes around text containing variables.

Commands: nano student.sh → save file → bash student.sh

Script – student.sh

#!/bin/bash
read -p "Enter your name: " student_name
read -p "Enter your student ID: " student_id
echo "Student: $student_name"
echo "ID: $student_id"
echo "Course: CSCI 300"

Example Terminal Output

student@ubuntu:~$ bash student.sh
Enter your name: Sara Ali
Enter your student ID: AUD12345
Student: Sara Ali
ID: AUD12345
Course: CSCI 300

💡 In nano, press Ctrl + O, Enter to save; Ctrl + X to exit. Use your own name and ID in the actual lab.

4 · 🔁 How Can a Script Repeat a Task and Calculate a Total?

First: Explanation. Repeating commands manually is slow. A for loop repeats instructions, and $(( ... )) performs integer arithmetic.

Repeat a blockfor ... do ... done repeats commands.
Generate numbers{1..5} gives 1, 2, 3, 4, and 5.
Calculatetotal=$((total + number)) adds each number.
Show resultecho displays the final total.

Commands: nano total.sh → save file → bash total.sh

Script – total.sh

#!/bin/bash
total=0
for number in {1..5}
do
    echo "Number: $number"
    total=$((total + number))
done
echo "Total: $total"

Example Terminal Output

student@ubuntu:~$ bash total.sh
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
Total: 15

💡 Initialize total=0 before the loop. Change {1..5} to {1..10} to get a total of 55.
