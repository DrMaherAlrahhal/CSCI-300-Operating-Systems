⌨️ Lesson 2 – How Can a C Program Read Student Information?

Use variables, printf, and scanf to work with numbers.

📖 First: Explanation

A program becomes more useful when it accepts information from the user. In C, a variable stores a value. printf displays text, and scanf can read a number typed in the Terminal.

Integer variableint age; creates a place to store a whole number.
Ask the userprintf displays a question.
Read the answerscanf("%d", &age) reads an integer into age.
Show the valueprintf("Age: %d\n", age) prints the saved number.

💻 Commands and Example C Program

nano student.c
gcc student.c -o student
./student
C source code – student.c
#include <stdio.h>

int main(void) {
    int age;
    printf("Enter your age: ");
    if (scanf("%d", &age) != 1) {
        printf("Please enter a whole number.\n");
        return 1;
    }
    printf("Course: CSCI 300\n");
    printf("Your age is %d\n", age);
    return 0;
}
Example Terminal output
student@ubuntu:~/CSCI300_Week6$ ./student
Enter your age: 20
Course: CSCI 300
Your age is 20
💡 Enter a whole number when the program asks for your age. The example checks whether scanf successfully reads a number.

🔀 Lesson 3 – How Can a C Program Make a Decision?

Use if and else to display Pass or Needs Improvement.

📖 First: Explanation

A C program can compare a value and choose what happens next. For example, a mark of 50 or more gives Pass; a lower mark gives Needs Improvement. We can use if, else, and comparison operators.

Read a markUse scanf("%d", &mark) to receive a number.
Check valid rangeMarks must be from 0 to 100.
Comparemark >= 50 means 50 or higher.
Choose outputif and else select one result.

💻 Commands and Example C Program

nano result.c
gcc result.c -o result
./result
C source code – result.c
#include <stdio.h>

int main(void) {
    int mark;
    printf("Enter your mark (0-100): ");
    if (scanf("%d", &mark) != 1 || mark < 0 || mark > 100) {
        printf("Invalid mark.\n");
        return 1;
    }
    if (mark >= 50) {
        printf("Result: Pass\n");
    } else {
        printf("Result: Needs Improvement\n");
    }
    return 0;
}
Example Terminal output
student@ubuntu:~/CSCI300_Week6$ ./result
Enter your mark (0-100): 75
Result: Pass

[Run again]
Enter your mark (0-100): 42
Result: Needs Improvement

[Run again]
Enter your mark (0-100): 120
Invalid mark.
💡 Use braces { } to show which instructions belong to if and else. The program checks invalid values before deciding the result.

🔁 Lesson 4 – How Can a C Program Repeat and Calculate?

Use a for loop to add the numbers from 1 to N.

📖 First: Explanation

Instead of writing many addition statements, a for loop repeats a calculation. The program asks for a positive number N, adds all integers from 1 to N, and displays the total.

Starting valueint total = 0; initializes the sum.
Loop counterint i = 1 starts counting from 1.
Repeat conditioni <= n continues until N is included.
Update totaltotal += i; adds the current number.

💻 Commands and Example C Program

nano total.c
gcc total.c -o total
./total
C source code – total.c
#include <stdio.h>

int main(void) {
    int n, total = 0;
    printf("Enter a number (1-100): ");
    if (scanf("%d", &n) != 1 || n < 1 || n > 100) {
        printf("Please enter a number from 1 to 100.\n");
        return 1;
    }
    for (int i = 1; i <= n; i++) {
        total += i;
    }
    printf("Sum from 1 to %d = %d\n", n, total);
    return 0;
}
Example Terminal output
student@ubuntu:~/CSCI300_Week6$ ./total
Enter a number (1-100): 5
Sum from 1 to 5 = 15

[Run again]
Enter a number (1-100): 10
Sum from 1 to 10 = 55
💡 The loop adds each number only once. Remember to compile the C program again after editing the source file.
