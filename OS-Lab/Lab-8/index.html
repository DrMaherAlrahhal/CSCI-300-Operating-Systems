PART A · UNDERSTAND

Understand the concept first

01 · THE CONCEPT

What is a function?

A function is a group of commands that has a specific name and performs a particular task.

Instead of writing the same commands many times, we write them once inside a function and call the function whenever we need it.

Define once→Call by name→Execute commands
02 · THE BENEFITS

Why do we use functions?

  • Reduce code repetition.
  • Make programs easier to understand.
  • Reuse the same code multiple times.
  • Make programs easier to modify and maintain.
03 · GENERAL SYNTAX

How do we create and call a function?

Define the function
function_name() {
    command1
    command2
}
→
Call the function
function_name

Use the function name without parentheses when calling it.

Defining a function does not execute its commands. Calling it does.

PART B · LEARN BY EXAMPLE

Practical example: greeting.sh

04 · WRITE THE SCRIPT

Create and run a Bash function

nano greeting.shbash greeting.sh
greeting.sh — Bash script
#!/bin/bash

greet() {
    echo "Welcome to CSCI 300!"
    echo "We are learning shell functions."
}

echo "Starting the program..."
greet
echo "Program finished."

In nano, press Ctrl + O, Enter to save; Ctrl + X to exit.

Understand each line
