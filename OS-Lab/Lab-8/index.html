Lesson 1 – How Can We Create and Call a Shell Function?

Define a function and run it by name.

📖 First: Explanation and Example

A function is a named group of commands. Instead of writing the same commands many times, we define them once and call the function whenever needed.

greet() { ... }Define a function named greet.
echoDisplay a message in Terminal.
greetCall the function to run its commands.
}End the function definition.
nano greeting.shbash greeting.sh
greeting.sh — example Bash script
#!/bin/bash
greet() {
    echo "Welcome to CSCI 300!"
    echo "We are learning shell functions."
}

echo "Starting the program..."
greet
echo "Program finished."
Example Terminal result
Starting the program...
Welcome to CSCI 300!
We are learning shell functions.
Program finished.
💡 Define the function before calling it. Bash uses the function name without parentheses when calling it.

Lesson 2 – How Can We Send Information to a Function?

Use function parameters such as $1.

📖 First: Explanation and Example

Functions become more useful when they accept information. Inside a function, $1 represents the first argument passed to it. We can use read to ask the student for a name and pass that name to a function.

read -r -pAsk the user to enter a value.
welcome_student "$name"Call the function with one argument.
$1Access the first function argument.
"$name"Keep the student's full name together as one argument.
nano student_welcome.shbash student_welcome.sh
student_welcome.sh — example Bash script
#!/bin/bash
welcome_student() {
    echo "Hello, $1!"
    echo "Welcome to the Operating Systems lab."
}

read -r -p "Enter your name: " name
welcome_student "$name"
Example Terminal result
Enter your name: Sara Ahmed
Hello, Sara Ahmed!
Welcome to the Operating Systems lab.
💡 For the last two steps, you can add read -r -p "Enter your ID: " student_id and call welcome_student "$name" "$student_id". Inside the function, print $2.

Lesson 3 – How Can a Function Make a Decision?

Pass marks to a function that checks the result.

📖 First: Explanation and Example

We can combine functions with decision making. The function receives a mark, checks it using if and else, and displays Pass or Needs Improvement. We can reuse the same function for different marks.

local mark="$1"Store the function argument in a local variable.
if (( mark >= 50 ))Check the passing threshold.
elseChoose the alternative result.
check_result 75Call the function with a particular mark.
nano check_result.shbash check_result.sh
check_result.sh — example Bash script
#!/bin/bash
check_result() {
    local mark="$1"

    if (( mark >= 50 )); then
        echo "Mark $mark: Pass"
    else
        echo "Mark $mark: Needs Improvement"
    fi
}

check_result 75
check_result 40
Example Terminal result
Mark 75: Pass
Mark 40: Needs Improvement
💡 Check the Excellent condition (mark >= 85) first, then Pass (mark >= 50), then the else case.

Lesson 4 – How Can Functions Process Several Numbers?

Combine a function, a loop, and arithmetic.

📖 First: Explanation and Example

A function can process several values. The special parameter "$@" represents all arguments. A for loop can visit each number, add them, and calculate an average. The local keyword keeps variables inside the function.

"$@"Access all arguments given to the function.
for number in "$@"Process each argument in turn.
local total=0Create a total variable inside the function.
$(( total / count ))Calculate an integer average.
nano calculate_average.shbash calculate_average.sh
calculate_average.sh — example Bash script
#!/bin/bash
calculate_average() {
    local total=0
    local count=$#
    local number

    for number in "$@"
    do
        total=$((total + number))
    done

    echo "Sum: $total"
    echo "Average: $((total / count))"
}

echo "Results for 5, 10, 15:"
calculate_average 5 10 15
Example Terminal result
Results for 5, 10, 15:
Sum: 30
Average: 10
💡 This example uses integer division. For 8, 12, 16, and 20, the sum is 56 and the average is 14. Do not call the function without numbers because that would divide by zero.
