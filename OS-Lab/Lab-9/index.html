Lesson 1 – How Can a C Program Ask the OS for Process Information?

Use getpid(), getppid(), and getuid() to inspect a running process.

📖 First: Explanation and Example

Every running program is a process. The operating system assigns each process an ID. A C program can ask the operating system for its process ID (PID), parent process ID (PPID), and user ID (UID) using system calls.

#include <unistd.h>Provides declarations for getpid(), getppid(), and getuid().
getpid()Returns the current process ID.
getppid()Returns the parent process ID.
getuid()Returns the user ID that owns the process.
nano process_info.cgcc process_info.c -o process_info./process_info
process_info.c — example C program
#include <stdio.h>
#include <unistd.h>

int main(void) {
    printf("My Process ID: %ld\n", (long)getpid());
    printf("Parent Process ID: %ld\n", (long)getppid());
    return 0;
}
Example Ubuntu Terminal output
My Process ID: 12345
Parent Process ID: 12001

(The numbers will be different on your computer.)
💡 Your PID and PPID are not fixed. The example numbers are illustrations only. Add printf("User ID: %ld\n", (long)getuid()); for the task.

Lesson 2 – How Can a C Program Create and Write to a File?

Use open(), write(), and close() to save text.

📖 First: Explanation and Example

A C program can ask the operating system to create a file and write bytes into it. open() gives the program a file descriptor, write() sends bytes to the file, and close() releases the descriptor.

open()Open or create a file; returns a file descriptor.
O_CREAT | O_TRUNCCreate the file if needed and replace old contents.
write()Write bytes from memory to the file.
close()Close the file descriptor when finished.
nano write_file.cgcc write_file.c -o write_file./write_file
write_file.c — example C program
#include <stdio.h>
#include <string.h>
#include <fcntl.h>
#include <unistd.h>

int main(void) {
    const char *message = "Hello from C system calls!\n";
    int fd = open("message.txt", O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) {
        perror("open");
        return 1;
    }

    if (write(fd, message, strlen(message)) == -1) {
        perror("write");
        close(fd);
        return 1;
    }
    close(fd);
    printf("File created and written successfully.\n");
    return 0;
}
Example Ubuntu Terminal output
$ gcc write_file.c -o write_file
$ ./write_file
File created and written successfully.
$ cat message.txt
Hello from C system calls!
💡 Keep message.txt in the same folder. You will read it in Task 3. O_TRUNC replaces the previous content each time you run the program.

Lesson 3 – How Can a C Program Read a File Using System Calls?

Use open(), read(), and close() to retrieve saved text.

📖 First: Explanation and Example

After writing message.txt, another program can open the same file and read its content. read() returns the number of bytes actually read. We use that value to add the end-of-string character before displaying the text.

O_RDONLYOpen a file for reading only.
read(fd, buffer, size)Read bytes into a memory buffer.
n > 0The number of bytes read successfully.
buffer[n] = '\0'Finish the text string before printing.
nano read_file.cgcc read_file.c -o read_file./read_file
read_file.c — example C program
#include <stdio.h>
#include <fcntl.h>
#include <unistd.h>

int main(void) {
    char buffer[256];
    int fd = open("message.txt", O_RDONLY);
    if (fd == -1) {
        perror("open");
        return 1;
    }

    ssize_t n = read(fd, buffer, sizeof(buffer) - 1);
    if (n == -1) {
        perror("read");
        close(fd);
        return 1;
    }
    buffer[n] = '\0';
    printf("File content:\n%s", buffer);
    close(fd);
    return 0;
}
Example Ubuntu Terminal output
$ gcc read_file.c -o read_file
$ ./read_file
File content:
Hello from C system calls!

(Your output will contain the text you saved in Task 2.)
💡 Add printf("Bytes read: %ld\n", (long)n); after reading. This example reads up to 255 bytes, which is enough for the short lab message.

Lesson 4 – How Can a C Program Create and Wait for a Child Process?

Use fork(), waitpid(), and process exit status.

📖 First: Explanation and Example

An operating system can create a new process from a running process. fork() creates a child process. The parent can use waitpid() to wait until the child finishes and then inspect its exit status.

fork()Create a new child process.
pid == 0This code is running in the child.
pid > 0This code is running in the parent.
waitpid()Wait for the child process to finish.
WEXITSTATUS(status)Get the child exit code after checking WIFEXITED.
nano fork_demo.cgcc fork_demo.c -o fork_demo./fork_demo
fork_demo.c — example C program
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main(void) {
    pid_t pid = fork();
    if (pid < 0) {
        perror("fork");
        return 1;
    }

    if (pid == 0) {
        printf("Child process: PID = %ld\n", (long)getpid());
        fflush(stdout);
        _exit(7);
    }

    int status;
    if (waitpid(pid, &status, 0) == -1) {
        perror("waitpid");
        return 1;
    }
    printf("Parent process: child finished.\n");
    if (WIFEXITED(status)) {
        printf("Child exit code: %d\n", WEXITSTATUS(status));
    }
    return 0;
}
Example Ubuntu Terminal output
$ gcc fork_demo.c -o fork_demo
$ ./fork_demo
Child process: PID = 12346
Parent process: child finished.
Child exit code: 7

(The PID will be different on your computer.)
💡 fork() runs the program in two processes. The child PID varies. Use fflush(stdout) before _exit() to ensure its message appears.
