System Calls in C: Understanding Processes

Understand how C programs request process information from Linux and create child processes. Learn the concepts first, follow the examples, then complete the Student Tasks 1 and 2 in Ubuntu Terminal.

2 lessonsTasks 1 & 2 only2 screenshot sectionsDownloadable lab report

Understand the concepts first

What is a system call?

A system call is a request from a running program to the operating system. The OS performs services that the program needs, such as identifying or creating processes.

C programRequests a service
→
Linux kernelHandles the request
→
ResultReturns to the program

What is a process?

A program is a set of instructions stored on a computer. A process is an instance of a program that is currently running.

Linux assigns each process a unique process ID (PID) while it is active. A process also has a parent and a user identity.

Task 1 – How Can a C Program Ask the OS for Process Information?

Use getpid(), getppid(), and getuid() to inspect a running process.

Understand the concept

1. What are PID, PPID and UID?

PID identifies the running process. PPID identifies its parent process. UID identifies the real user associated with the process.

Two running instances of the same program normally have different PIDs.

2. How are processes related?

Ubuntu shellExample PID: 12001
starts ↓
process_infoPID: 12345 · PPID: 12001

The shell is the parent in this example. Actual IDs depend on your computer.

3. How can C obtain these IDs?

getpid() → current process ID

getppid() → parent process ID

getuid() → real user ID

Include <unistd.h> to use these functions. Include <stdio.h> to print the results.

4. How does the program execute?

StartRun ./process_info
→
Request IDsCall getpid() and getppid()
→
DisplayPrint the returned values

The task asks you to add getuid() and print the user ID too.

Practical example — create, compile and run

process_info.c — example C program
#include <stdio.h>
#include <unistd.h>

int main(void) {
    printf("My Process ID: %ld\n", (long)getpid());
    printf("Parent Process ID: %ld\n", (long)getppid());
    return 0;
}

(The numbers will be different on your computer.)
💡 Your PID and PPID are not fixed. The example numbers are illustrations only. Add printf("User ID: %ld\n", (long)getuid()); for the task.

Task 2 – How Can a C Program Create and Wait for a Child Process?

Use fork(), waitpid(), and process exit status.

Understand the concept

1. What are parent and child processes?

A running process can create another process. The original process is called the parent; the new process is called the child.

Both continue from the call to fork(), but each has its own PID and execution path.

2. What does fork() return?

Original processpid_t pid = fork();
↓ creates a child ↓
Childpid == 0
Parentpid > 0 (child PID)

If pid < 0, creation failed and no child was created.

3. Why does the parent wait?

waitpid(pid, &status, 0) makes the parent wait for the specified child to finish in this example. The child uses _exit(7) to end with exit code 7.

WIFEXITED(status) checks normal termination; WEXITSTATUS(status) then retrieves the exit code.

4. What is the execution order?

Parentfork()waitpid() — waitsPrint exit code
ChildCreatedPrint PID_exit(7)

The parent prints its completion message only after the child has finished. fflush(stdout) ensures the child’s printed message is flushed before _exit().

Practical example — create, compile and run

nano fork_demo.cgcc fork_demo.c -o fork_demo./fork_demo
fork_demo.c — example C program
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main(void) {
    pid_t pid = fork();
    if (pid < 0) {
        perror("fork");
        return 1;
    }

    if (pid == 0) {
        printf("Child process: PID = %ld\n", (long)getpid());
        fflush(stdout);
        _exit(7);
    }

    int status;
    if (waitpid(pid, &status, 0) == -1) {
        perror("waitpid");
        return 1;
    }
    printf("Parent process: child finished.\n");
    if (WIFEXITED(status)) {
        printf("Child exit code: %d\n", WEXITSTATUS(status));
    }
    return 0;
}
Example Ubuntu Terminal output
$ gcc fork_demo.c -o fork_demo
$ ./fork_demo
Child process: PID = 12346
Parent process: child finished.
Child exit code: 7

(The PID will be different on your computer.)
💡 fork() runs the program in two processes. The child PID varies. Use fflush(stdout) before _exit() to ensure its message appears.
